# Reader fonts

Flood bundles these open source fonts for consistent offline reading:

- Source Serif 4: https://github.com/google/fonts/tree/main/ofl/sourceserif4
- Inter: https://github.com/google/fonts/tree/main/ofl/inter

The corresponding SIL Open Font License text is included beside each font.
The font files were downloaded from the `main` branch on 2026-09-11.
